# web/

The ChartsTV web app (Next.js 16): the whole TV UI plus the `/api/news` and `/api/whats-moving` routes. See the [main README](../README.md) for features, URL flags, setup and architecture.

```bash
npm install
npm run dev    # http://localhost:3000
npm test
```

Before writing code here, read `AGENTS.md`: this Next.js version has breaking changes from older releases.
